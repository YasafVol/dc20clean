# Classes

- Added the 5th level Expert Features to all Classes
- Casters gain +1 MP at levels 3, 7 and 10
- Hybrids gained +1 MP at levels 1 and 10

## Class Tables

- Level 6 is now a Talent and Path Progression
- Level 7 is now Subclass Expert Features
- Level 8 is now a Talent, Path Progression and 2 Ancestry Points
- Level 9 is now a Class Capstone
- Level 10 is now a Subclass Capstone

## Barbarian

- Elemental Fury Subclass
 - Changed Elemental Blast's Spell Check to be an Area Spell Attack
- Swift Berserker Class Talent has been removed

## Champion

- Fighting Spirit
 - Renamed Brace to be Fortify as to not confuse it with the Brace Manuever
 - Added Martial Attack Check to Advance

## Cleric

- Channel Divinity
 - Cleaned up the wording and made it a once per combat feature.
- Divine Blessing
 - Corrected the checks used in the Destruction Blessing

## Commander

- Inspiring Presence
 - Changed to once per round
 - Increased its range to 10
 - Added an interaction with Death's Door

## Monk

- Spiritual Balance
 - Changed to be 2 Ki points and you regain 1 Ki on SP regain or when combat ends, you also regain all Ki on long rest.
 - Uncanny Dodge cost has been reduced to be 1 Ki

## Rogue

- Cheap Shot
 - Changed Invisibility to Invisible as Invisibility is not a Condition
- Swashbuckler
 - Fixed the DC tip to have the correct value of a passive penalty

## Spellblade

- Made it so the stamina regen is easier to acquire
- Fixed the Fire Bolt typo in the Spellstrike examples
